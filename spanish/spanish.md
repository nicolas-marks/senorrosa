# Señor Rosa Spanish Page

## Goal
Create a new Spanish-learning page for Señor Rosa at:

**senorrosa.com/spanish**

## Core Feature
Build a concise, easy-to-scan verb chart covering the **50 most commonly used verbs in Mexican Spanish**.

For each verb, include conjugations for:

- Yo
- Tú
- Él / Ella / Usted
- Ellos / Ellas / Ustedes
- Nosotros / Nosotras

The page should prioritize practical, conversational Mexican Spanish rather than academic completeness.

## Direction
Keep the page useful as a quick-reference tool for real-world Spanish practice. The verb chart is the main feature, with room to add practical example sentences and other study tools later.
